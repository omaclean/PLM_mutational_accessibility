# Working notes

These are the working documents of the analysis, kept in the repository for transparency
rather than for use. **Nothing here is needed to validate the paper** — for that, start from
the root [`README.md`](../../README.md) and the reference documents it lists.

They are working notes in the ordinary sense: written while the work was going on, sometimes
superseded by what came later, and in places arguing with each other. Where a note and a
reference document disagree, the reference document is current.
