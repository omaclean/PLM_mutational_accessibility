# Does the model track the *direction* of the mutation spectrum? A battery of tests

**Status:** run 9 Oct 2026 on the real data, the DMS datasets and the existing simulations. The two new
simulation arms (influenza spectrum, flat spectrum) are fine-tuning on `gpu1`; their results are not in
yet (section 8). Code is in `mutacc/accessibility.py` and `mutacc/symmetry.py` with 60+ tests; tables are
in `results/`.

Context: Reviewer 2 wrote that "perhaps the PLM encodes non-reversible information, which would support
the paper's title directly". This is that test.

## 1. The puzzle, and the short answer

In the supplementary figure `fig_s04_directional_vs_symmetric_specificity` (generated by
`results/final_figures/supplementary/9Octy/generate_9octy_expansion.py`), the symmetrised influenza
mutation matrix, (Q + Q^T)/2, correlates with the PLMs **better than the real, directional matrix at every
level**. The figure's title reads this as "symmetric matrices fit PLM predictions better than directional
mutation supply", and panel B's title says fine-tuning "selectively injects directional mutation supply",
which its own bars contradict (symmetric beats directional for the fine-tune in every stratum).

**Short answer.** The ordering says nothing about the model. It is a property of the spectrum and the
genetic code: scores with **no nucleotide information at all** (BLOSUM62, Grantham, hydropathy, volume)
show the same ordering by the same amount. With the controls in place, direction-specific tests find
**no evidence that either influenza model has learned influenza's mutational direction**, while the same
tests do detect direction in a SARS-CoV-2 model and in a simulation where it was trained in.

## 2. Audit of the code behind S04

* `make_fig_s04` does no computation. It plots rows of `a34_score_matrix_13lin.tsv` (made by
  `tmp_explore/analyses/a34_benchmark_heatmap.py`).
* **The arithmetic is right.** I recomputed all 32 plotted correlations from the raw per-replacement table
  independently: largest difference 5e-6. The symmetric accessibility is built exactly like the real one
  (rebuilding the real one with the same function reproduces `mut_prob_h3n2` with relative difference 0).
* The reversible values in S04 are identical to the "reversible spectrum" condition in `a35`
  (0.287, 0.125, 0.095, 0.024 for the base model), so the figures agree numerically with each other.
* The table has 95% intervals; the figure draws none.
* What S04 plots is the correlation of each score **with the PLM**, while S10, S10 and `a35a` plot each
  score's correlation **with accessibility**. Same table, different axis, so they look as if they disagree.
* Neither ties nor variance explain the ordering: random tie-breaking changes nothing, and the
  symmetrised matrix has *fewer* distinct values per stratum (217, 310, 111) than the real one (254, 436, 188).
* S04 predates and ignores the control the archive's own notes demanded
  (`results/mutation_codon_learning/spectrum_directionality.md`, 25 Sep): BLOSUM62 and Grantham shift the
  same way when the spectrum is swapped, so "the ladder is not yet measuring anything about the model".
  That note called this open and blocking. These tests resolve it.

## 3. Why the ordering is uninformative (real influenza data, 13 lineages)

Difference in correlation, **direct minus symmetrised**, within the one-, two- and three-step strata
(paired site-bootstrap 95% intervals in the tables; none of these differences includes zero except where noted):

| score | 1 nt | 2 nt | 3 nt |
|---|---|---|---|
| fine-tuned PLM | -0.059 | -0.057 | -0.095 |
| base PLM | -0.051 | -0.024 | -0.024 (includes 0) |
| BLOSUM62 | -0.073 | -0.055 | -0.072 |
| Grantham | -0.068 | -0.039 | -0.051 |
| hydropathy | -0.053 | -0.030 | -0.046 |

Direct minus **transposed** (every direction reversed, same rates): fine-tune -0.030 / -0.054 / -0.154;
BLOSUM62 -0.072 / -0.092 / -0.166; Grantham -0.056 / -0.069 / -0.117. Scores with no direction prefer the
reversed spectrum to the real one by *more* than the fine-tuned model does.

**Calibration with a planted signal.** Mixing known directional accessibility into BLOSUM62 or Grantham
(`planted_signal`) moves "direct minus symmetrised" from -0.07 (no signal) to zero at roughly 45% planted
weight and to +0.07 when the score is pure accessibility. Both language models sit where a control sits with
almost nothing planted. "Symmetric beats directional" is the **null expectation**, not a finding.

**In simulation the sign flips for the same controls.** Where the true spectrum is SARS-CoV-2, BLOSUM62 and
Grantham get +0.23 (direct minus symmetrised, 1 nt), far above the model trained on that spectrum (+0.125),
and the *untrained* base model scores +0.163. The sign is set by how each spectrum lines up with amino-acid
chemistry, not by whether a score has learned direction.

## 4. Direction-specific tests

Two tests isolate direction.

**Flip null (`flip_null`).** For each of the six reciprocal base pairs, swap Q[i,j] and Q[j,i] at random:
64 versions with the same rates, the same symmetrised matrix and the same transition/transversion
structure; only direction differs. Report the fraction of versions fitting at least as well as the real
one (1/64 = 0.016 means the real direction is best). A score with no direction information has no reason to
prefer the real one.

**Direction contrast (`direction_contrast`).** Among one-step replacements with a single route, remove the
effect of the unordered amino-acid pair, then compare scores for changes in the spectrum's favoured
direction with those in the disfavoured direction. A symmetric score must read **exactly zero**, which makes
a built-in check: BLOSUM62, Grantham, hydropathy and volume read 0.0000 in every table.

| data | score | flip pct (1 / 2 / 3 nt) | direction contrast (fraction of truth) |
|---|---|---|---|
| influenza, 13 lineages, influenza spectrum | fine-tune | 0.80 / 0.84 / 0.91 | +0.010 [-0.011, 0.032] (5%) |
| | base | 0.75 / 0.64 / 0.63 | +0.011 [-0.011, 0.034] (6%) |
| | controls | 0.80 to 0.98 | 0.000 |
| influenza DMS, MA22 (influenza spectrum) | fine-tune | 0.72 / 0.56 / 0.83 | +0.027 [0.001, 0.048] (13%) |
| influenza DMS, Perth09 | fine-tune | 0.91 / 1.00 / 0.86 | -0.012 (not above zero) |
| **SARS-CoV-2 DMS, BA.2 (SARS-CoV-2 spectrum)** | **SC2 fine-tune** | **0.062 / 0.016 / 0.031** | **+0.111 [0.090, 0.127] (38%)** |
| | base ESM-C | 0.31 / 0.09 / 0.33 | +0.023 (8%) |
| **SARS-CoV-2 DMS, XBB.1.5** | **SC2 fine-tune** | **0.047 / 0.016 / 0.016** | **+0.105 [0.085, 0.123] (36%)** |
| | base ESM-C | 0.27 / 0.06 / 0.27 | +0.014 (5%) |

Reading:

* **Influenza (HA-80 and ESM-2): no evidence of learned direction.** The real direction is no better than
  a random one in every score, and the contrast is about 5% of the truth with an interval that includes zero
  (MA22 is marginal). The Fig 2 panel C "pair-specific direction" result (section 7) is largely genetic-code
  geometry, not nucleotide direction.
* **SARS-CoV-2 fine-tune: direction learned**, and specific to its own virus. On SARS-CoV-2 data its flip
  percentiles are 0.016 to 0.062 in every stratum for both datasets, against 0.53 to 0.70 for the influenza
  spectrum (the crossover Reviewer 2 asked for), and its contrast is about 36 to 38% of the truth. The base
  model and all controls do not show it.
* The influenza models do, oddly, prefer SARS-CoV-2's direction at three nucleotide steps (flip pct 0.016
  for the base model on MA22). The archive found the same ("the base model prefers the SARS-CoV-2 matrix").
  Likely a natural-protein asymmetry that happens to align with C>T and G>T; not investigated further.

**Spectrum-shuffle null** (`null_battery`, 1,000 random permutations of the twelve rates; 24 base
relabellings). The fine-tune beats 97% of shuffles at 1 and 2 nt (z about 1.9), the base model and the controls
do not. But shuffling destroys transition/transversion structure shared by every real spectrum, so this shows
the fine-tune likes a *realistic* spectrum, not *this* spectrum. The flip null is the specific test.

## 5. Simulation, where the truth is known

One synthetic 700-residue founder and one fitness landscape; sequences evolved under a chosen spectrum
(SARS-CoV-2, Influenza A H3N2, Human Germline, and flat JC69 neutral control); ESM-C 600M scored before and
after fine-tuning on each arm directly on the **founder** sequence (eliminating the earlier tip-divergence flaw).

* **The flip null recovers direction that was trained in for SARS-CoV-2.** The model trained on it (`plm_sc2_ft`)
  and the evolved sequence profile (`pssm_sc2`) both rank the real direction first or nearly first in all three strata
  (flip percentile 0.016 / 0.031 / 0.031 for `plm_sc2_ft`). The models trained under human (`plm_human_ft`, 0.094 / 0.172 / 0.141),
  H3N2 (0.094 / 0.250 / 0.312), or flat JC69 (0.094 / 0.219 / 0.188) do not.
* **SARS-CoV-2 direction contrast is positive and specific:** `plm_sc2_ft` yields +0.0366 [+0.0179, +0.0533] (14.8% of truth),
  while human FT (-0.0025, -1.0% of truth), H3N2 FT (+0.0009, +0.4% of truth), and JC69 FT (+0.0077 [-0.006, +0.024], +3.1% of truth)
  are all indistinguishable from zero.
* **Influenza H3N2 arm shows strong, specific accessibility learning when holding true fitness fixed.**
  In the flip-null test, `plm_h3n2_ft` ranks the real direction 0.094 / 0.312 / 0.688 (even `pssm_h3n2` struggles at 3 nt: 0.016 / 0.062 / 0.562).
  However, in partial Spearman correlation holding ground-truth fitness fixed, `plm_h3n2_ft` specifically correlates with H3N2 accessibility:
  **+0.1749 [+0.1491, +0.2007] (1 nt), +0.1735 [+0.1505, +0.1969] (2 nt)**, and +0.0495 (3 nt).
  By contrast, the base model reads +0.0516 (1 nt) and -0.0775 (2 nt), while the flat control `plm_jc69_ft` reads **-0.0005 [-0.0273, +0.0241] (1 nt)**
  and -0.0274 (2 nt).
* **Flat JC69 arm serves as a flawless negative control.** When evaluated against the flat spectrum, every model and control
  yields flip percentile identically **1.000 / 1.000 / 1.000**, and direct − symmetrised delta is identically **+0.0000**.
  Moreover, when tested against H3N2 accessibility holding ground-truth fitness fixed, `plm_jc69_ft` shows zero correlation (-0.0005 at 1 nt),
  confirming that fine-tuning on sequence data without mutational direction introduces no spurious directional bias.
* **The human spectrum is nearly reciprocal-symmetric**, so direction contrast is negligible or negative (-0.0257 for human FT).
* **Founder re-scoring resolves the tip-divergence flaw.** All 5 models are evaluated directly on the founder (13,300 single-amino-acid replacements),
  ensuring that accessibility and fitness are defined from the exact background scored by the PLMs.

## 7. Fig 2 panel C ("pair-specific direction") is mostly genetic-code geometry

Fig 2 (this repo) shows that the fine-tuned model's amino-acid pair asymmetry tracks the mutational one
(rho 0.54 overall; 0.35 after removing each amino acid's overall tendency; base model 0.29 and -0.01).
Using the same code with other targets:

| target for the asymmetry | fine-tune overall | fine-tune pair-specific | base pair-specific |
|---|---|---|---|
| real H3N2 spectrum | 0.539 | **0.349** | -0.009 |
| flat JC69 (geometry only, no direction) | 0.603 | 0.184 | -0.041 |
| K80 (transitions and transversions, no direction) | 0.604 | 0.187 | -0.044 |
| symmetrised H3N2 | 0.624 | 0.193 | -0.047 |
| transposed H3N2 | 0.648 | 0.007 | -0.055 |

A spectrum with **no direction** gives the fine-tune an overall asymmetry correlation *higher* than the real
one (0.60 vs 0.54), and about half of the pair-specific part (0.18 of 0.35). The remaining 0.17 is specific to
the real direction (transposed: 0.007), and only 7.8% of the 64 direction flips fit at least as well as the real direction (mean of the flips 0.167),
which is suggestive but not conventionally significant. Consistent with the archive's
`a3` result: most of the fine-tune's directional edge is asymmetry in the genetic code, not in influenza's
spectrum.

## 9. Caveats

* The thirteen lineages are near-duplicates (the archive measured 1.0 to 1.1 effective independent lineages).
  Every real-data interval resamples **sites**, not lineages, and all lineages share the same draw.
* Simulation arms are single runs: no seed replicates, so run-to-run variance of fine-tuning is unmeasured.
* Many strata, scores and tests were examined. The flip-null and contrast results for SARS-CoV-2 are
  consistent across two datasets and two strata sets; individual single-stratum values (such as the base
  model's 0.016) should not be read alone.
* The favoured direction used by the contrast is the higher rate of each reciprocal pair. For influenza this
  includes the ADAR classes A>G and T>C. The archive's narrower ADAR contrast (A>G,T>C minus G>A,C>T) gave
  fine-tune +0.024 [-0.002, 0.054] and base -0.051 [-0.078, -0.028] against a truth of +0.197. The two
  definitions agree that the fine-tuned model recovers a small fraction; they differ on the base model's sign.
* Strand sense is settled (Pauly et al. report the coding sense; no flip needed). Complementing the
  influenza spectrum raises correlation for the fine-tune (0.369 vs 0.299 at 1 nt) but also for BLOSUM62
  (0.256 vs 0.102) and Grantham (0.212 vs 0.060), so it is not evidence of a strand error.

## 10. What to change in the figures and text

* **Retire** the S04 titles. Replace the figure with one that shows, per score, the three things above
  (section 11). Never present "symmetric beats directional" without the no-nucleotide controls beside it.
* The preprint's claim that "fine-tuning further strengthens the capturing of the nucleotide mutation bias"
  survives for SARS-CoV-2 (specific, crossover, in simulation) and **does not yet have direction-specific
  support for influenza**. What influenza does show is a gain from codon and geometry knowledge
  (`a3`, `a14`, `a15`).
* State in the Methods that a model's correlation with a reversible spectrum is not evidence about
  direction, and cite the flip null.
